Features

What the workspace is for

  • 01 —

    Multi-model chat

    Talk to models from Gemini, Groq, and Cloudflare. If one path is busy, the app can try another.

  • 02 —

    Saved threads

    Keep prompts and replies in your workspace so you can pick up a conversation where you left off.

  • 03 —

    Keys stay on the server

    Model calls go through your Worker, not the browser, so API secrets are not exposed in the page.

How it works

Three steps, then you iterate

  1. 01 —

    Describe the task

    Write what you need in plain language — a draft, a plan, a summary, or a question.

  2. 02 —

    Get an answer back

    NovaMind sends the prompt to a model from your Worker and returns the reply in the same thread.

  3. 03 —

    Keep the work

    Save the conversation, attach a file for more context, or start the next task from the same place.

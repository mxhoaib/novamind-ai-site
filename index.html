Features

What the workspace is for

Practical tools for everyday writing and thinking — described as they are intended to work, without inflated claims.

Multi-model chat

Talk to models from Gemini, Groq, and Cloudflare. If one path is busy, the app can try another.

Saved threads

Keep prompts and replies in your workspace so you can pick up a conversation where you left off.

File context

Attach notes or documents when you want a reply grounded in your own material, stored in object storage.

Edge-fast API

Requests run on Cloudflare Workers, close to you, so the interface stays snappy on a normal connection.

Keys stay on the server

Model calls go through your Worker, not the browser, so API secrets are not exposed in the page.

Works on any screen

A responsive web app you can use on a phone or a desktop. There is no app-store step.

How it works

Three steps, then you iterate

The intended flow of the workspace, from a prompt to a saved thread.

01 — Prompt

Describe the task

Open the workspace and write what you need in plain language — a draft, a plan, a summary, or a question.

02 — Reply

Get an answer back

NovaMind sends the prompt to a model from your Worker and returns the reply in the same thread.

03 — Keep going

Keep the work

Save the conversation, attach a file for more context, or start the next task from the same place.
